# GUI-only dependencies for label_gui.py AND test_image_gui.py. Separate
# from requirements-training.txt (training/inference can run headless on a
# server; these GUIs need a desktop with Qt). Best known-good pins as of
# this writing; verify against https://pypi.org/project/PyQt6/ if install
# fails.
#
# test_image_gui.py ALSO needs requirements-training.txt installed (for
# ultralytics, to run inference) -- not merged into this file since that
# one's heavy (torch) and training-only setups shouldn't need Qt.
#
# Pillow is left unpinned on purpose: a pinned old version (e.g. 10.4.0) has
# no prebuilt wheel for newer Python releases (seen failing on Python 3.14 --
# pip then tries to compile from source and needs zlib headers, which aren't
# present on a typical Windows machine). Letting pip pick the latest
# compatible Pillow avoids that entirely.
PyQt6==6.7.1
Pillow
# label_gui.py reads data.yaml directly, independent of whether
# requirements-training.txt is installed -- so pyyaml is listed here too.
