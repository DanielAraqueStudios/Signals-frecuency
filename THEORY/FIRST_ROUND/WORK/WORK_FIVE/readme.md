# AM Signal & Aliasing Analysis Lab

> Part of the [`Signals-frecuency`](../../../../Readme.md) repository — see the root
> README for the full project index.

Generates a 60 Hz tone and an AM signal `(2 + sin(2π·60t))·sin(2π·f_c·t)`,
compares sampling the AM signal at an under-Nyquist rate (`fs=10^5` Hz,
`f_c=1 kHz`) against a properly sampled rate (`fs=10^6` Hz, `f_c=100 kHz`),
and plots time-domain waveforms plus FFT spectra for both.

---


`fs=10^6` Hz with a 100 kHz carrier.

## API Reference

### `am_lab.signals`

| Function | Description |
|---|---|
| `sample_times(duration_s, sample_rate)` | Builds a `[0, duration_s)` time axis |
| `tone_signal(t, frequency_hz)` | Pure sine, `sin(2π·f·t)` |
| `modulated_signal(t, message_freq_hz, carrier_freq_hz)` | AM signal `(2 + sin(2π·f_msg·t))·sin(2π·f_carrier·t)` |

### `am_lab.spectrum`

| Function | Description |
|---|---|
| `single_sided_fft(signal, sample_rate, max_freq_hz=None)` | Single-sided, amplitude-normalized FFT: `(frequencies, magnitude)`, optionally capped at `max_freq_hz` |

## Signal Processing Notes

- The two AM cases use **different carrier frequencies on purpose**
  (1 kHz at `fs=10^5`, 100 kHz at `fs=10^6`) so that both stay comfortably
  under Nyquist (`fs/2`) for their own sampling rate — this is a
  side-by-side comparison of two correctly-sampled regimes, not a
  demonstration of aliasing on the same signal.
- The AM envelope `2 + sin(2π·60t)` ranges over `[1, 3]`, so the modulated
  signal's amplitude is bounded by `±3` regardless of carrier frequency.
- `single_sided_fft` normalizes magnitude by `N/2` so a unit-amplitude sine
  shows a peak of ~1.0 in its spectrum; the DC/Nyquist bins are not
  bin-count-corrected, which only matters for signals with real content at
  those exact bins.

## Testing

```bash
python -m pytest tests/ -v
```

9 tests cover `am_lab.signals` (sample count, endpoint exclusion, closed-form
tone/AM agreement, envelope amplitude bound) and `am_lab.spectrum` (dominant
peak recovery for a known tone, non-negative frequency output, `max_freq_hz`
capping, amplitude normalization).
