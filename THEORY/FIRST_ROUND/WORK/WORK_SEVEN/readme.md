# Moving-Average Filter Lab

> Part of the [`Signals-frecuency`](../../../../Readme.md) repository — see the root
> README for the full project index.

Implements **Tarea 3-C**: a digital moving-average (boxcar) low-pass filter,
sized by target cutoff frequency, applied to sine, square-wave, and real
audio signals, with before/after time-domain and FFT plots for every case.

- **C.1** — filter at 40Hz and 100Hz, for sine signals A and B.
- **C.2** — filter at 40Hz, 70Hz, and 120Hz, for square-wave versions of A and B.
- **C.3** — filter at 40Hz and 100Hz, for the cat audio recording.

---

## Scope

Signals A and B reuse `WORK_FIVE`'s definitions (`fs = 10^5` Hz):

- **A**: `sin(2*pi*60*t)` — a 60 Hz tone.
- **B**: `(2 + sin(2*pi*60*t)) * sin(2*pi*1000*t)` — a 1 kHz carrier amplitude-modulated by a 60 Hz message.

For C.2, A and B are rebuilt with every `sin(...)` swapped for a
`scipy.signal.square(...)` of the same frequency (same generator WORK_THREE
uses for its ideal square wave).

## Signal Processing Notes

- **Moving-average filter**: a normalized boxcar FIR filter,
  `y[n] = (1/N) * sum_{k=0}^{N-1} x[n-k]`, applied via `mode="same"`
  convolution so the output stays the same length as the input.
- **Cutoff -> window length**: the moving average's frequency response is a
  Dirichlet kernel (periodic sinc). Its -3dB point is well approximated by
  `f_c ~= 0.443 * fs / N` (Steven W. Smith, *The Scientist and Engineer's
  Guide to Digital Signal Processing*, ch. 15 — the constant 0.443 solves
  `|sinc(0.443)| = 1/sqrt(2)` for the boxcar's mainlobe), so
  `cutoff_to_window` inverts it: `N = round(0.443 * fs / f_c)`. Larger `N`
  (lower cutoff) means stronger smoothing and a lower -3dB point; the 40 Hz
  cases in every sub-part therefore use a noticeably wider window than the
  100/70/120 Hz cases.
- **C.1 (sine)**: at `fc = 40Hz`/`100Hz`, both well below A's 60 Hz tone and
  B's 1 kHz carrier, the filter attenuates both signals heavily — the
  40 Hz case attenuates more (wider window) than 100 Hz.
- **C.2 (square)**: a square wave's energy is spread across its fundamental
  and all odd harmonics (Fourier series, per `WORK_THREE`). A boxcar
  low-pass with a 40-120 Hz cutoff removes most of those harmonics, leaving
  a rounded, near-sinusoidal shape instead of the original sharp edges —
  visible directly in the FFT panels as harmonics above the cutoff being
  suppressed.
- **C.3 (audio)**: the filter is applied to a short (50 ms) segment of the
  cat recording rather than the full file, matching `WORK_FOUR`'s rationale
  — a filtering result plotted over the full multi-second recording is too
  dense to read as individual samples; nothing stops running
  `moving_average_by_cutoff` against the full-length signal instead.

## Testing

```bash
python -m pytest tests/ -v
```

15 tests cover:
- `avg_filter_lab.filters`: the `cutoff_to_window` formula, its minimum-1
  clamp and positive-cutoff validation, `moving_average_filter`'s
  window-length validation, that a constant (DC) signal passes through
  unchanged away from the edges, output-length preservation, and that a
  high-frequency tone is attenuated more than a low-frequency tone by the
  same cutoff.
- `avg_filter_lab.waveforms`: `sample_times`' window, and closed-form checks
  for `sine_tone`, `sine_am`, `square_tone` (bounded/bipolar), and
  `square_am`.
- `avg_filter_lab.audio`: `segment()`'s time-window slicing (deterministic,
  no audio file needed) and a real-file smoke test on the checked-in cat
  recording, skipped gracefully if the file is missing.
